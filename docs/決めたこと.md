# 立体将棋のルール（2026-10-30 決定）

## 盤と向き
- 9×9×9。マスは「筋（1〜9）・段（一〜九）・層（1〜9）」で呼ぶ
- **どの層も普通の将棋の盤と同じ向き。** 先手は七〜九段側（手前）、後手は一〜三段側（奥）で向かい合う
- 駒の「前」は相手の方向（先手は一段の方向、後手は九段の方向）。上下（層）は両者共通
- 2026-10-30 変更: 最初は上下（1層と9層）で向かい合っていたが、各層を普通の将棋のように見せたいので変えた

## 初期配置（片側180枚）
- **どの層にも普通の将棋の初期配置**を並べる（九段に香桂銀金玉金銀桂香、八段に角・飛、七段に歩。後手も同様）
- 玉は 5層だけ（先手 5九5層、後手 5一5層）。ほかの8つの層では玉の位置に金を置く

## 駒の動き（「横」= 筋の方向、「上下」= 層の方向、「斜め」= 2軸を同時、「立体の対角線」= 3軸を同時）
- 玉: まわり26マスに1マス
- 飛: 前後・左右・上下の6方向に走る ＋ 横と上下の斜め4方向に1マス
- 角: 斜め12方向 ＋ 立体の対角線8方向（計20方向）に走る
- 金: 前の段の9マス（横・上下にずれた所も含む）・同じ段の8マス・真後ろ1マス（18マス）
- 銀: 前の段の9マス ＋ 後ろの段で横にずれた6マス（15マス）
- 桂: 前へ2段進み、横・上下の8方向のどれかに1マスずれる（8か所。飛び越せる）
- 香: 真っすぐ前に走る ＋ 左右・上下に走る
- 歩: 前に1マス。同じ層・1つ上の層・1つ下の層の3か所から選べる（2026-10-30 変更: 真っすぐ前だけでは立体的でないので）
- 龍: 飛の動き ＋ まわり26マスに1マス。馬: 角の動き ＋ まわり26マスに1マス
- と・成香・成桂・成銀: 金と同じ（成香は香より弱くなるので、成るかは選べる）
- 1つの層の中だけで見ると、金・銀・桂・歩・玉・角は普通の将棋と同じ動き
- 二歩の禁止は打つときだけ（普通の将棋と同じ）。歩が上下の層へ動いた結果、同じ層の同じ筋に歩が2枚並ぶのは反則にしない

## その他
- 成れる場所: 相手側の3段（先手なら一〜三段。どの層でも）
- 持ち駒はどこにでも打てる。二歩は同じ層の同じ筋で判定
- 打ち歩詰めは禁止
- 行き所のない駒: 歩は最後の段、桂は最後の2段に打てず、進むときは必ず成る（香は横に動けるので制限なし）
- 玉を詰ませたら勝ち。同じ局面が4回で引き分け
- CPU は、持ち駒を打つ場所が多すぎて深く読めないので、駒の取り合いを読む程度にする
