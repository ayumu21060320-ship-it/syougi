# 立体将棋のルール（2026-10-30 決定）

## 盤と向き
- 9×9×9。マスは「筋（1〜9）・段（一〜九）・層（1〜9）」で呼ぶ
- 先手は 1層（下）側、後手は 9層（上）側。上下で向き合う
- 駒の「前」は相手の方向（先手は上、後手は下）

## 初期配置（片側180枚。後手は上下反対の同じ形）
- 普通の将棋の最初の3段を、9つの段それぞれに並べる（どの段で切っても普通の将棋の初期配置の断面になる）
- 1層: 各段に「香桂銀金○金銀桂香」。○は五段だけ玉、ほかは金（81枚）
- 2層: 各段の 8筋に角、2筋に飛（18枚）
- 3層: 全部のマスに歩（81枚）
- 2026-10-30 変更: 最初は十字の形で片側38枚だったが、駒をぎっしり並べた見た目にしたいので変えた

## 駒の動き（斜め＝2軸を同時に動く／立体の対角線＝3軸を同時に動く）
- 玉: まわり26マスに1マス
- 飛: 前後・左右・上下の6方向に走る ＋ 同じ層の中の斜め4方向に1マス
- 角: 斜め12方向 ＋ 立体の対角線8方向（計20方向）に走る
- 金: 前の層の9マス・同じ層の8マス・真後ろ1マス（18マス）
- 銀: 前の層の9マス・後ろの層の四隅4マス（13マス）
- 桂: 前へ2層進み、平面の8方向のどれかに1マスずれる（8か所。飛び越せる）
- 香: 真っすぐ前に走る ＋ 同じ層の中の前後左右に走る
- 歩: 真っすぐ前に1マス
- 龍: 飛の動き ＋ まわり26マスに1マス。馬: 角の動き ＋ まわり26マスに1マス
- と・成香・成桂・成銀: 金と同じ（成香は香より弱くなるので、成るかは選べる）

## その他
- 成れる場所: 相手側の3層（先手なら7〜9層）
- 持ち駒はどこにでも打てる。二歩は同じ縦の列（筋・段が同じ）で判定
- 打ち歩詰めは禁止
- 行き所のない駒: 歩は最後の層、桂は最後の2層に打てず、進むときは必ず成る（香は横に動けるので制限なし）
- 玉を詰ませたら勝ち。同じ局面が4回で引き分け
- CPU は、持ち駒を打つ場所が多すぎて深く読めないので、最初は駒の取り合いを読む程度にする
