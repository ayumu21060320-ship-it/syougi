# 将棋

ブラウザで遊べる将棋ゲームです。ビルド不要、`index.html` を開くだけで動きます。

## 遊び方

1. `index.html` をブラウザで開く
2. 動かしたい駒（または駒台の持ち駒）をクリックすると、指せるマスに印が出ます
3. 印のマスをクリックして指します。成れるときは「成る／成らない」を選べます

### 機能

- 対局モード：CPU と対局（先手・後手を選択）／2人で対局
- CPU の強さ：弱い・普通・強い
- 待った（CPU 対局では自分の手番まで戻ります）・投了
- 棋譜表示（KIF 風の表記）
- ルール判定：王手放置の禁止、二歩、打ち歩詰め、行き所のない駒、成りの強制、詰み、千日手（同一局面 4 回で引き分け）

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `css/style.css` | 見た目 |
| `js/shogi.js` | ルールエンジン（合法手生成・局面更新・棋譜表記） |
| `js/ai.js` | CPU の思考（駒得を評価する αβ 探索） |
| `js/ui.js` | 盤の表示とクリック操作 |

## テスト

Node.js で実行できます。

```bash
node test/perft.js
```

```bash
node test/rules.js
```

`perft.js` は初期局面からの合法手の数を既知の値（30 / 900 / 25470 / 719731）と照合し、`rules.js` は二歩・打ち歩詰めなどの特殊ルールを確認します。
